# GeosangManager 공식 다운로드

**GeosangManager**는 거상 상단 관리와 다양한 편의 기능을 제공하는 Windows용 프로그램입니다.

이 저장소는 GeosangManager의 공식 설치 파일, 업데이트 및 사용자 매뉴얼을 배포합니다.

---

## 📥 다운로드

### [최신 버전 다운로드 (GitHub Releases)](https://github.com/jshcry-byte/GeosangManager-Releases/releases/latest)

| 항목 | 안내 |
|---|---|
| 지원 환경 | Windows 64비트 |
| 설치 파일 | `GeosangManager-버전-Setup.exe` |
| 설치 권한 | 관리자 권한 불필요 |

처음 설치하는 사용자는 **Setup.exe**를 다운로드하세요. 이전 버전을 별도로 설치할 필요는 없습니다.

버전별 변경사항과 이전 설치 파일은 [전체 릴리즈 목록](https://github.com/jshcry-byte/GeosangManager-Releases/releases)에서 확인할 수 있습니다.

## 🚀 설치 방법

1. 위의 **최신 버전 다운로드** 링크를 클릭합니다.
2. `GeosangManager-버전-Setup.exe` 파일을 다운로드합니다.
3. 다운로드한 설치 파일을 실행합니다.
4. 설치가 완료되면 시작 메뉴 또는 생성한 바탕화면 바로가기에서 실행합니다.
5. 최초 실행 시 필요한 PC 인증 절차를 진행합니다.

**기본 설치 위치**

`%LOCALAPPDATA%\Programs\GeosangManager`

설치 프로그램은 현재 Windows 사용자 계정에 설치되며 관리자 권한을 요구하지 않습니다.

## ⚠️ Windows 보안 경고

현재 GeosangManager 설치 파일은 코드 서명되지 않았습니다.

따라서 Windows SmartScreen 또는 브라우저에서 다운로드·실행 경고가 표시될 수 있습니다.

공식 GitHub 릴리즈에서 다운로드한 파일인지 확인한 뒤, 다음 절차를 참고하세요.

- **Microsoft Edge 다운로드 경고:** `유지 → 더 보기 → 계속 유지`
- **Windows 보호 화면:** `추가 정보 → 실행`

메뉴 이름은 Windows 및 브라우저 버전에 따라 다를 수 있습니다.

출처가 불분명하거나 악성코드 탐지 경고가 발생한 파일은 실행하지 마세요. 백신이나 Windows 보안 기능을 비활성화하지 마세요.

**[다운로드 경고 및 공식 파일 확인 안내](manuals/사용자매뉴얼.md#installation-warnings)**

## 🔐 PC 인증 안내

GeosangManager는 PC 인증 절차를 제공하며, 최초 등록이나 PC 변경 시 추가 인증 과정이 필요할 수 있습니다.

PC 등록, 초대 코드, 승인 수령, PC 교체 및 재신청 방법은 아래 매뉴얼을 참고하세요.

**[PC 인증 따라하기](manuals/사용자매뉴얼.md#0-pc-인증-따라하기)**

## 🔄 업데이트 방법

GeosangManager는 새로운 버전이 배포되면 업데이트를 확인할 수 있습니다.

### 자동 업데이트

1. 프로그램에서 새로운 버전 알림을 확인합니다.
2. 업데이트에 동의하면 파일을 다운로드하고 검증합니다.
3. 프로그램이 정상 종료된 후 업데이트를 적용하고 재실행합니다.

### 수동 업데이트

1. [최신 릴리즈](https://github.com/jshcry-byte/GeosangManager-Releases/releases/latest)에서 Setup.exe를 다운로드합니다.
2. 실행 중인 GeosangManager를 정상 종료합니다.
3. 설치 파일을 실행하여 기존 버전을 업데이트합니다.

**기존 사용자 DB, 설정 및 PC 인증정보는 업데이트 시 유지됩니다.**

업데이트를 위해 PC 등록을 해제할 필요는 없습니다.

## 📌 안내사항

- 이 저장소는 공식 프로그램 배포 전용입니다.
- 소스 코드와 운영 데이터는 포함하지 않습니다.
- 사용자 DB와 설정은 Windows 사용자 영역에 보관됩니다.
- 공개 GitHub 다운로드에 사용자 인증정보를 전송하지 않습니다.
- 업데이트 및 변경사항은 GitHub Releases를 통해 안내합니다.
